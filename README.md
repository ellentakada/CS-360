Briefly summarize the requirements and goals of the app you developed. What user needs was this app designed to address? 

- The inventory application helps to manage inventory items. The application can keep track of quantity, add, update and delete each inventory. Notification is available to let users know when an inventory item reaches zero. The application addresses user needs by offering central management for inventory items through the application. 

What screens and features were necessary to support user needs and produce a user-centered UI for the app? How did your UI designs keep users in mind? Why were your designs successful? 

- There are a total of three screens; login screen, inventory screen and notification screen. Each screen has text input and button to interact with data. For UI design, I chose to have a light green for primary color and dark green for secondary color on every screen, to make it consistent and visually appealing. I believe my design was successful as it gives comfort by having enough margin between each item.  

How did you approach the process of coding your app? What techniques or strategies did you use? How could those be applied in the future? 

- I approached the process with a lot of preparation. This includes going through documentation, drafting, and reviewing textbooks. From time management perspective, I spent small to medium amount of time from very early on. This was effective and can be applied in future, as it is almost always the case to have to spend extra time and work than anticipated. 

How did you test to ensure your code was functional? Why is this process important and what did it reveal? 

- I tested with Emulator, and test cases include both success and failure. This was important to confirm that it behaves as expected from implementation. It revealed some minor mis-implementation such as input type for text box. I also used logcat for the debugging process. 

Considering the full app design and development process, from initial planning to finalization, where did you have to innovate to overcome a challenge? 

- For a full application design, I would have to more detailed planning on documentation by including sample images. I would also have to run a project in Agile model, which I work closely with client and confirm development. I would also need to come up with a list of test scenarios and record results to create UAT. 

In what specific component from your mobile app were you particularly successful in demonstrating your knowledge, skills, and experience? 

- The application was successful for displaying real-time records. This was achieved by implementing fragment, view model, repository, database relationship. For the database, I used Dao as an interface to send queries to database.
